### 收錄範圍與限制

「搜尋走完」只代表這次搜尋可見的範圍，不代表完整帳號歷史匯出。Facebook 的排序、權限與內容可能改變。7 則同文 AI 討論只展開一份全文，其餘依相同開頭和圖像歸類；部分重複討論未保存個別永久連結。沒有年份的貼文日期保留 Facebook 原標籤，不推定年份。

三筆來源中的儲存庫拼字與實際網址不同，對應修正是依官方專案內容所作推定，已在項目說明中保留原字串與修正理由。

展示網址來自官方儲存庫，但未逐一測試第三方展示的互動功能。GitHub 星數來自 2026-10-04 的 GitHub API 快照，各筆記錄包含 UTC 時間與來源網址；排序僅比較本次收錄項目，不是全球熱門排名，也不代表品質。

### 程式碼與素材授權

開源標示指核對過的程式碼授權，不保證整個展示的模型、音樂、文字或商標可以自由重用。特別注意：

- messenger-copy 的 MIT 程式碼不包含原作 Messenger 素材，原專案明示不得未經許可再散布該素材
- Prehistoric Animal Museum 的程式碼為 AGPL-3.0-only，原創文字、旁白與背景等另採 CC BY-NC-SA 4.0，第三方模型另有條款
- Claude of Tanks 的現行程式碼含專有範圍，列在「其他來源與授權限制」，沒有計入完整開源程式碼目錄
- iCraft 為商業專有授權，沒有計入開源目錄
- 只有 package.json 宣告授權、未查得授權全文的項目暫不列為已驗證

各項目均有查核依據及說明，使用時請閱讀原作者的最新授權文件。

## 功能與隱私

- 名稱／介紹／標籤搜尋、分類篩選、星數或名稱排序
- 專案詳情、官方展示、程式碼、授權與來源連結
- 收藏僅存於此瀏覽器的 localStorage；不會上傳
- 響應式桌面／手機布局、鍵盤操作、系統減少動態效果偏好
- 沒有第三方追蹤、外部字型、CDN 腳本或 WebGL 需求
- 網站幾何插圖為原創裝飾，並非各專案的展示截圖

## 本機預覽

在此資料夾執行：

```sh
python3 -m http.server 8000
```

開啟 `http://localhost:8000`。請勿直接以 `file://` 開啟，因為瀏覽器可能阻擋 `data.json` 讀取。

## 檢查

只需 Node.js，不需安裝 npm 相依套件：

```sh
npm test
npm run check:publish
```

`npm test` 檢查 JavaScript 語法、資料結構，以及 URL 安全性、授權篩選、搜尋、分類、排序、未知／零星數和收藏篩選等 18 項單元斷言。`check:publish` 另驗證來源覆蓋、分類結果與來源連結數量。這些檢查不代表第三方展示已完成互動測試。

## GitHub Pages

將本資料夾內容放在儲存庫根目錄，使用 GitHub Pages 的分支或 Actions 靜態部署。所有應用程式路徑均為相對路徑，支援 `/<repository>/` 子路徑；`.nojekyll` 避免不必要的 Jekyll 處理。

## 資料結構

- `metadata`：來源範圍、觀測日期、統計及限制
- `projects`：已驗證開源程式碼的專案
- `excludedProjects`：授權或範圍有其他限制的來源，不計入開源總數
- `otherSourceResults`：沒有可驗證儲存庫的搜尋主題與原因

新項目須附官方儲存庫、實際授權全文、來源貼文及查核日期。未知資料用 null，不能猜測星數、授權、展示網址或全球名次。
